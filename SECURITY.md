# Security Policy

## Supported versions

Security fixes are maintained for the latest published stable release of SEOmi.
Use the release assets from this repository to obtain updates.

## Report a vulnerability

Please use GitHub's private vulnerability reporting:

[Report a vulnerability privately](https://github.com/tomaszboloz/SEOmi/security/advisories/new).

Include the affected SEOmi version, operating system, steps to reproduce,
expected and actual behavior, and the potential impact. A minimal reproduction
with synthetic data helps us investigate.

Do not include API keys, OAuth tokens, passwords, or private project data in
reports, logs, or screenshots. Do not publish exploit details in a public issue
while the report is being investigated.

## Coordinated disclosure

Maintainers review private reports and coordinate remediation and disclosure
with the reporter. Confirmed fixes and contributor acknowledgments are included
in release notes. Public bug reports without security-sensitive details can
continue to use the repository's Issues page.
