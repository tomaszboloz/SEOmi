- This is local, uncommitted worktree evidence only; no main-branch SHA, CI, native release, signed artifact, production monitoring, or deployment claim.
- Non-EN/PL language rules are intentionally `uncertain`; no claim of calibrated NLP quality or Google AI Overview citation behavior is made.
- The local lexical SPO/self-containment implementation is a transparent heuristic and does not provide dependency parsing, NER, entailment, or factual verification.
- Existing legacy history records without profile metadata remain readable; explicit migration/recompute and UI trend-break presentation belong to the profile-migration acceptance flow.
- UI rewrite integration is intentionally untouched and remains with `ai_trust_ui_resume`; the DTO fields to consume are profile, availability/languageStatus, offsets, issues/spans, SPO quality/negation, AnswerFirst availability, and extractability normalization.
- Issue #108 threshold calibration and real comparable-crawl monitoring evidence remain outside this local engine patch; unavailable/unknown data must not produce a zero score or alert.
- The threshold harness is a reproducible labeled synthetic fixture set, not a validated production dataset; no precision/recall or real-world calibration claim is made.
- A legacy crawl without persisted `aio_profile` is intentionally skipped by monitoring until an explicit profile migration/recompute records the new identity.
